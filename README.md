# deepseek-pp-skills

Personal [DeepSeek++](https://github.com/zhu1090093659/deepseek-pp) Skills collection.

Sync these skills across devices via **Skill → GitHub 导入 (GitHub Import)**.

## Skills

| Skill | Description |
|-------|-------------|
| `sisyphus` | Autonomous agentic loop for coding, terminal execution, and verification. |
| `allthing` | Deep multi-perspective analysis, ultra reasoning, and autonomous recursive tool execution loop. |
| `1` | OPTIMAL EXECUTION PIPELINE — REASON & DEBATE → AUTONOMOUS ACTION → VERIFY & SELF-CORRECT with FACT GATE and failure-log memory. |

## Structure

```
skills/
  sisyphus/SKILL.md
  allthing/SKILL.md
  1/SKILL.md
```

Each `SKILL.md` carries YAML frontmatter (`name`, `description`) plus the instruction body.

## Usage

In DeepSeek++ sidebar:

1. Skill → GitHub 导入
2. Paste repo URL: `https://github.com/gunlee41/deepseek-pp-skills`
3. Select skills → import
4. Later: Skill → 检查上游更新 (check upstream updates) to pull changes

No GitHub login or token is required (public repo).
